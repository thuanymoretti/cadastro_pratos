Como executar o projeto?:

1.Instale e abra o XAMPP.
2.Inicie os serviços Apache e MySQL.
3.Coloque a pasta do projeto dentro de: "C:\xampp\htdocs\"
4.Abra o phpMyAdmin pelo XAMPP e crie o banco de dados do projeto.
5.Execute o arquivo SQL para criar as tabelas usuarios e pratos.
6.Confira os dados de conexão no arquivo: "infra/conexao.php"
7.No navegador, acesse:
http://localhost:(numero da sua porta no XAMPP)/(nome da sua pasta)/(nome da pasta com o código)/
8.Com o Apache e o MySQL ligados, o sistema estará pronto para ser utilizado.
